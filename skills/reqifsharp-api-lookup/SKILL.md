# reqifsharp API lookup

The reference is generated by reflection over the ReqIFSharp and ReqIFSharp.Extensions assemblies
the CLI bundles, together with their shipped XML documentation.

`<plugin-root>` is the plugin root from the reqifsharp-sage SessionStart context (or two
directories above this skill's base directory).

## Read order

1. Read `<plugin-root>/knowledge/installed.json` and take `api.reqIFSharpVersion` as `<pv>`. If
   `api` is missing, use `knowledge-setup` (`generate` builds the reference) and stop.
2. Compare `<pv>` with the version the user's project references (`<PackageReference Include="ReqIFSharp" Version=...>`,
   or `Directory.Packages.props`). If they differ, say so. When the user works in the reqifsharp
   repository itself, the source code is the truth and this reference describes the released
   package.
3. `<plugin-root>/knowledge/reqifsharp/<pv>/index.json` is an array of
   `{name, fullName, namespace, assembly, kind, isAbstract, isStatic, reqifClass, xmlElement, file}`.
4. Read `<plugin-root>/knowledge/reqifsharp/<pv>/types/<FullName>.md`. It contains:
   - the declaration and doc summary;
   - inheritance and derived types;
   - **ReqIF mapping**: the metaclass, the `<XML-ELEMENT>`, and a feature table from C# property
     to ReqIF feature to XML name;
   - constructors and methods with full C# signatures and parameter docs;
   - property tables;
   - **Extension methods available**, including those declared for base types;
   - inherited members.
5. `mapping.json` holds the whole ReqIF class ↔ C# type ↔ XML element map. Query it with `jq`:
   `jq -r '.entries[] | select(.xmlElement=="SPEC-HIERARCHY") | .csharpType' mapping.json`.
   `api.json` is the full machine-readable model.

## Naming differences to know

C# names mostly equal the metaclass names, but some features differ:

| C# property | ReqIF feature |
|---|---|
| `Description` | `desc` |
| `AlternativeId` | `alternativeID` |
| `DataTypes` | `datatypes` |
| `ToolExtension` | `toolExtensions` |
| `IsMultiValued` | `multiValued` |

`ExternalObject` is a reqifsharp-only helper with no ReqIF element: attachments referenced from
XHTML `<object data=...>` in a `.reqifz`.

## Answering

- Tag facts as **API**, with the package and version ("ReqIFSharp 10.1.2").
- Quote signatures exactly as the page gives them, and never invent overloads or members. If
  something is not in the reference, say so.
- For how-to questions (reading, writing, `.reqifz`, validation), combine this with the
  `reqifsharp-usage` skill.
